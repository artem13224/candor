# UX "laws": evidence grades

Cite a law only at the strength its evidence supports. Many popular "laws" (Laws of UX, design blogs) are repeated uncritically. Use this table to avoid passing on weak claims, and to correct a client who cites them.

| Principle | Evidence | Correct use · common misuse |
|---|---|---|
| **Fitts's Law** | **Strong.** Mathematical model (1954) | Big, near targets for primary actions; hit area can exceed visuals. *Misuse:* "screen corners are infinite" applies to desktop operating systems, not inside a web page or on touch screens. |
| **Hick–Hyman Law** | **Strong but narrow.** Reaction time to known, equally likely choices | Cut, group and default. *Misuse:* setting menu lengths; searching an unfamiliar list is serial, not logarithmic. |
| **Jakob's Law / mental models** | **Strong** convention | Familiar patterns for navigation, forms and checkout; spend novelty on content. |
| **Gestalt** (proximity, similarity, common region, connectedness, Prägnanz) | **Strong** perceptual basis | Spacing and containers do the grouping. |
| **Miller's Law (7±2)** | **Misapplied.** About working memory; Cowan puts it nearer 4 | Chunk what users must *carry* between steps. *Misuse:* "menus ≤7 items" (menus are scanned, not memorised). |
| **Cognitive load** (Sweller) | **Good** | Remove extraneous load (noise, decoration in task areas). |
| **Doherty Threshold (400 ms)** | **Weak.** IBM 1982, commercial motive | Use Nielsen's 0.1 / 1 / 10 s limits instead. *Never* add fake delays. |
| **Peak-End Rule** | **Good** (Kahneman 1993; clinical replications) | Fix the worst moment; design the ending. |
| **Serial position** | **Good** (recall of lists) | Key items first or last. |
| **Von Restorff / selective attention** | **Good** | One distinctive element per view; banner blindness kills ad-like emphasis. |
| **Aesthetic-usability effect** | **Good** (Kurosu & Kashimura 1995, n=252) | Beauty earns forgiveness *and* hides problems in tests. |
| **Goal-gradient effect** | **Moderate** (Kivetz 2006) | Honest progress indicators. *Misuse:* "artificial progress". |
| **Zeigarnik effect** | **Failed replication.** 2025 meta-analysis of 59 studies: recall ratio ~0.99 | Use the *Ovsiankina* effect (people resume interrupted tasks) with resumable state. Don't claim a memory boost. |
| **Choice overload / paradox of choice** | **Conditional.** Mean effect ~0 (Scheibehenne 2010); real under four moderators (Chernev 2015) | Recommend a default, allow comparison. *Misuse:* the 24-vs-6 jam study as proof. |
| **Anchoring** | **Strong** (Tversky & Kahneman 1974) | Order prices deliberately; anchors must be real. |
| **Default effect** | **Strong** (organ donation, pension auto-enrolment) | Pre-select what serves users. |
| **Social proof** | **Strong** when real and similar | Specific, attributable, never low numbers, never fake. |
| **Processing fluency** | **Good** | Legibility reads as truth and competence. *Misuse:* disfluency to "make people think" (a 2015 replication found no benefit). |
| **Tesler's Law** | Principle | Move complexity onto the system, not the user. |
| **Postel's Law** | Engineering principle | Accept messy input, normalise it, give clear feedback. |
| **Pareto principle** | Heuristic | Prioritise the 20% of tasks that most users do. |
| **Golden ratio** | **Folklore** (Markowsky 1992) | A taste choice for editorial splits or type; not evidence. Alignment beats it. |
| **F-pattern / Z-pattern / Gutenberg** | F: eye-tracking (a *fallback* when structure is weak) · Z: a designer's heuristic · Gutenberg: homogeneous text pages only | Front-load headings; strong hierarchy turns scanning into the layer-cake pattern. |
| **Banner blindness** | **Good** (1998 onward; NN/g eye tracking) | Don't style key content like ads; animation makes it look *more* like an ad. |
| **Curse of knowledge** | **Good** (Newton's tapping study) | Only outsiders find jargon; test with first-time users. |
