# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

**Candor** — a static marketing website for a B Corp and sustainability certification consulting business (Vancouver, BC). Deployed on Netlify from the repo root with no build step.

## Commands

There is no build system. The only automation scripts are:

```bash
# Rebuild blog/index.html whenever a new .html post is added to /blog/
node blog-watcher.js

# Full publish pipeline: copy post, inject card, update sitemap, git commit & push
node publish.js path/to/post.html

# Dry run (no file writes or git ops)
node publish.js path/to/post.html --dry-run
```

`publish.js` extracts metadata from the post's `<h1>`, `.article-tag`, `.article-lede`, and `<time dateTime>` elements, then injects a card into `blog/index.html` and appends a `<url>` to `sitemap.xml`.

## Architecture

Static vanilla HTML/CSS/JS — no frameworks, no bundler, no TypeScript.

| Path | Role |
|---|---|
| `index.html` | Main landing page (~136 KB, all styles inline) |
| `assessment/index.html` | Interactive BIA impact-assessment tool; Canvas-based topographic background; multi-screen quiz flow managed in vanilla JS |
| `blog/index.html` | Blog listing; auto-regenerated by `blog-watcher.js` / `publish.js` |
| `blog/*.html` | Individual blog posts |
| `Brand Guide/` | Design-system reference (HTML, CSS, JSX component previews) |
| `images/` | All static assets (SVG logo, JPG hero images, PNG favicons) |
| `netlify.toml` | Deployment config, security headers, and cache rules |
| `sitemap.xml` | Updated by `publish.js` on each post publish |

## Styling conventions

All styles are written in `<style>` blocks embedded in each HTML file using CSS custom properties. The design token set is consistent across pages:

```css
--bg: #ECEAE2;        /* page background */
--ink: #0E110D;       /* primary text / dark bg on assessment page */
--green: #2D6B42;     /* primary brand green */
--field: #3D8A57;
--sage: #5aA672;
--oat: ...;
--paper: #F5F3EE;
--u: "Urbanist", sans-serif;   /* headings & UI */
--mono: "Space Mono", monospace;
--ease: cubic-bezier(.16,1,.3,1);
```

Body text uses Open Sans. Never introduce an external CSS framework or utility library.

## Deployment

Netlify publishes the repo root directly. Key rules in `netlify.toml`:
- HTML files are never cached (`Cache-Control: no-cache, no-store`).
- JS, CSS, fonts, and images are cached with `immutable` / long `max-age`.
- `/blog/:slug` rewrites internally to `/blog/:slug.html` (status 200).
- Security headers are set on all routes (strict CSP, HSTS, X-Frame-Options DENY).

When adding a new top-level page or route, check whether a corresponding redirect/rewrite rule is needed in `netlify.toml`.

## Structured data & SEO

`index.html` embeds Schema.org JSON-LD (Organization, LocalBusiness, Person, Offers, FAQPage). Keep this in sync when adding or removing services or FAQ entries. `robots.txt` and `sitemap.xml` must stay consistent with live pages.
