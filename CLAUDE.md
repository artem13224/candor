## Commands

```bash
# Watch /blog/ and auto-rebuild blog/index.html when new posts are added
npm run watch          # or: node scripts/blog-watcher.js

# Full publish pipeline: copy post → inject card → update sitemap → git commit & push
npm run publish path/to/post.html   # or: node scripts/publish.js path/to/post.html

# Dry run — preview without writing files or running git
node scripts/publish.js path/to/post.html --dry-run
```

`publish.js` extracts metadata from the post's `<h1>`, `.article-tag`, `.article-lede`, and `<time dateTime>` elements. It injects a card into `blog/index.html`, appends a `<url>` block to `sitemap.xml`, then commits with message `blog: publish {slug}` and pushes.

## Blog system

### Post requirements

Every post must have these elements for `publish.js` and `blog-watcher.js` to extract metadata correctly:

```html
<h1>Post title here</h1>
<span class="article-tag">Category</span>
<p class="article-lede">Short excerpt shown on card</p>
<time dateTime="YYYY-MM-DD">Month YYYY</time>
```

Also include in `<head>`:
- `<title>Title | Candor</title>`
- `<meta name="description" content="...">`
- `<meta name="article:section" content="...">`
- JSON-LD with `"datePublished": "YYYY-MM-DD"`

### Card logic in blog/index.html

- **Newest post** (by `datePublished`) → featured dark card (multi-column layout)
- **All other posts** → regular cards in reverse chronological order

## Deployment

Netlify publishes the repo root directly. Key `netlify.toml` rules:

| Rule | Detail |
|---|---|
| HTML caching | `Cache-Control: public, max-age=0, must-revalidate` (never cached) |
| JS/CSS | `immutable`, `max-age=31536000` |
| Images | `max-age=2592000` (30 days) |
| Fonts | Immutable, long-term |
| Blog rewrite | `/blog/:slug` → `/blog/:slug.html` (status 200) |

**Security headers on all routes:**
- `X-Frame-Options: DENY`
- `Content-Security-Policy` — allows `'unsafe-inline'` (needed for inline styles/scripts), Calendly, Google Fonts, Google Analytics
- `Strict-Transport-Security` with preload (1 year)
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy`: blocks camera, microphone, geolocation

When adding a new top-level page or route, check whether a redirect/rewrite rule is needed in `netlify.toml`.

| URL | Priority | Changefreq |
|---|---|---|
| `/` | 1.0 | monthly |
| `/blog/` | 0.9 | monthly |

### robots.txt

- Blocked: Yandex, Baidu, AhrefsBot, SemrushBot, Scrapy, CCBot, DotBot, and others
- Allowed: Googlebot, Bingbot, Google-Extended, GPTBot, ChatGPT-User, ClaudeBot, PerplexityBot
- Crawl-delay: 2 seconds
- Disallowed paths: `/admin/`, `/wp-admin/`, `/api/`
